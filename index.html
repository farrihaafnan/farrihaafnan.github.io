scCrossGEN: cross-organ single-cell transcriptomic translation

Some organs are hard to sample from a living donor. scCrossGEN generates a donor's single-cell transcriptomes for such an organ from cells collected in an accessible one, and learns from unpaired data.

Cells from an accessible organSingle-cell RNA-seq from one donor
scCrossGENVAE with adversarial training, CycleGAN-inspired
Cells for a hard-to-sample organSame donor, generated

ResultOutperforms scGen and scPRAM across multiple organ systems.

Methods and keywords
  • CycleGAN-inspired, VAE-based generative framework with adversarial training.
  • Translates single-cell transcriptomes between organs from cell-level unpaired data.

Patient-specific deterioration pathways from ICU data

ICU mortality models output a risk score but not the clinical path that leads to it. This project recovers, for each patient, the sequence of interacting events that drives deterioration.

ICU recordsVitals, labs and interventions, irregular in time
Event graphClinical concepts as nodes, timed relations as edges
Temporal graph networkWith an edge-importance module
Risk and pathwayMortality prediction plus the events behind it
Methods and keywords
  • Multimodal, continuous-time event graphs built from irregular longitudinal ICU records.
  • A temporal graph network for mortality prediction, with an edge-importance module that extracts each patient's deterioration pathway.

Multi-omics disease prediction via graph-based cross-modal imputation
